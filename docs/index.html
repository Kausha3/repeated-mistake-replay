This hosted preview contains synthetic data. The downloadable tool runs locally without sign-up, API keys, model calls or uploading a trace. For a real investigation, replace the fixture with an authorized redacted trace and preserve what is known, unknown, and independently observed. Hebbrix is in private beta. Applications record a decision and attach its later result; Hebbrix uses those results to guide later decisions.
