Where Hebbrix fits

An application records a decision and attaches the result when it becomes known. Hebbrix uses those results to guide later decisions. We call this outcome-based learning. Developers connect through Python, TypeScript or MCP. Hebbrix is in private beta.

This inspector is a separate, open-source evidence checklist. It does not call Hebbrix or measure product performance.

If you maintain a workflow where a corrected mistake repeats, describe it to the Hebbrix founders. The GitHub issue is public and requires a GitHub account. Keep logs, customer data and credentials private. A discussion does not book an appointment or establish an evaluation agreement.

For a high-level inquiry without a public issue, use Hebbrix's contact page. Keep the trace private until a suitable route is agreed.

Examples are authored synthetic records. User-supplied records are declarations, not independently verified evidence. Read the source, limitations and tests. No analytics or third-party assets are included.
